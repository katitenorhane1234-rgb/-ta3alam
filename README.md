# T3alam | تعلّم
منصة لتعلّم القراءة والكتابة والحساب بالعربية للكبار. HTML + CSS + JavaScript فقط، بلا تثبيت.

## التشغيل
افتح `index.html` مباشرة، أو انشرها على GitHub Pages:
Settings ← Pages ← Branch: main ← Save.

## الفكرة
المتعلم يختار ما يريد من الرئيسية: الحروف، الكلمات، الكتابة، الأرقام، الحساب، التمارين. لا شيء مقفول.
التقدم (ما تعلّمه، النجوم، المحاولات) يُحفظ في المتصفح على نفس الجهاز.

## الصوت
يستعمل ملفات mp3 من مجلد `audio/` إن وُجدت (اسم الملف = النص تماماً، مثل `باء.mp3` و`بَاب.mp3`)، وإلا يستعمل أفضل صوت عربي متاح في الجهاز.

## ملاحظات
- لوحة الكتابة لا تصحح الخط آلياً.
- لإضافة كلمات عدّل مصفوفة `WD` في app.js (المقاطع تُفصل بشرطة).
