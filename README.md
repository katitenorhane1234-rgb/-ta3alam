# T3alam | تعلّم

منصة ويب عربية أولية لتعليم الكبار القراءة والكتابة والحساب.

## التشغيل
افتح `index.html` في متصفح حديث. لا يحتاج المشروع إلى تثبيت حزم.

## الملفات
- `index.html`: هيكل الصفحات والأقسام.
- `styles.css`: التصميم المتجاوب.
- `app.js`: التفاعل والدروس والصوت والتمارين وحفظ التقدم.

## الوظائف
- الحروف: أسماء الحروف، أشكال حرف الباء، الحركات، المدود، اختبار تمييز الحروف، مساحة تتبع وكتابة.
- الكلمات: مفردات مصنفة، نطق صوتي، تقسيمات توضيحية، تمرين كتابة واختبار استماع.
- الأرقام: الأرقام 1 إلى 20 بالشكل 1, 2, 3...، أسماؤها، ربطها بالكميات، مساحة كتابة، جمع وطرح بسيطان.
- حفظ إحصائيات التمارين محلياً باستخدام `localStorage`.

## رفعه على GitHub
1. أنشئ مستودعاً جديداً باسم `T3alam`.
2. ارفع الملفات الثلاثة وملف README إلى جذر المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/ (root)`.
5. احفظ وانتظر نشر GitHub Pages.

## ملاحظات
- النطق العربي يعتمد على الأصوات المتوفرة في المتصفح والجهاز.
- تقسيم الكلمات أمثلة أولية ويحتاج إلى مراجعة تربوية ولغوية قبل اعتماد المنهج.
- مساحة الرسم تتيح التتبع والكتابة الحرة، لكنها لا تقيّم صحة الخط آلياً.
- التقدم محفوظ على الجهاز والمتصفح نفسيهما، ولا توجد حالياً حسابات أو قاعدة بيانات مركزية.
