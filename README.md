# T3alam | تعلّم
منصة ويب لمحو الأمية بالعربية للكبار: HTML + CSS + JavaScript بدون أي تثبيت أو خادم.

## التشغيل
افتح `index.html` مباشرة، أو انشرها على GitHub Pages:
1. أنشئ مستودعاً وارفع الملفات الأربعة (index.html, styles.css, app.js, README.md).
2. Settings ← Pages ← Branch: main ← Save.

## المحتوى
7 مستويات متدرجة (كل مستوى يُفتح باجتياز اختبار المستوى السابق بـ 3 من 5): الحروف، الأشكال، الحركات، المدود، الكلمات، الكتابة (3 محاولات)، الأرقام والحساب.
التقدم يُحفظ في localStorage على نفس الجهاز.

## ملاحظات
- النطق عبر SpeechSynthesis ويعتمد على وجود صوت عربي في الجهاز.
- لوحة الكتابة بالـ Canvas ولا تصحح الخط آلياً.
- الصور رموز Emoji لتعمل دون اتصال.
- لإضافة كلمات عدّل مصفوفة `WD` في app.js (المقاطع تُفصل بشرطة).
